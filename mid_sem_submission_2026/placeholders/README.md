# Image Capture List

Use these exact filenames in the `figures` folder.

| Filename | What the image should show |
|---|---|
| `dashboard_live.png` | Large calibrated pitch, player and ball markings, session clock, stream status, selected player |
| `dashboard_analytics.png` | Selected event on the shared timeline, pitch state, team-shape and workload explanation |
| `dashboard_wearable.png` | Player-device link, packet age, signal quality, GPS fix, BPM, SpO2 estimate, IMU values |
| `hardware_front.jpg` | Enclosure, strap, sensor contact area, power control, and cable strain relief |

Crop screenshots so browser tabs, personal notifications, tokens, Wi-Fi passwords, and unrelated windows are not visible. Use real live values from the controlled session. Do not edit values into a screenshot.
